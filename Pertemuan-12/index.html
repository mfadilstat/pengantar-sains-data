1. Regresi Linear Sederhana (Simple Linear Regression)¶

Regresi Linear Sederhana adalah model statistik paling dasar yang memodelkan hubungan linear antara satu variabel bebas (X) dan satu variabel terikat (Y). Model mengasumsikan bahwa perubahan pada X menghasilkan perubahan proporsional pada Y, ditambah error acak.

Asumsi klasik OLS (BLUE — Best Linear Unbiased Estimator):

  • Linearitas: hubungan X dan Y harus linear
  • Normalitas error: residual berdistribusi normal N(0, sigma^2)
  • Homoskedastisitas: varians error konstan untuk semua nilai X
  • Non-autokorelasi: error tidak berkorelasi satu sama lain
  • Exogeneity: X tidak berkorelasi dengan error

Ket:

beta_0 = intercept (nilai Y saat X=0), beta_1 = slope (perubahan Y per unit X), epsilon = error, Y_bar = rata-rata Y, SSE = Sum of Squared Errors, SST = Total Sum of Squares, s^2 = MSE = SSE/(n-2).

Regresi Linear Berganda (Multiple Linear Regression)¶

Regresi Linear Berganda memperluas regresi sederhana dengan menggunakan dua atau lebih variabel bebas (X1, X2, ..., Xp) untuk memprediksi Y. Model ini memungkinkan kita mengontrol pengaruh variabel lain saat mengestimasi efek masing-masing prediktor. Konsep penting tambahan:

  • Adjusted R^2: R^2 yang dikoreksi untuk jumlah prediktor — lebih adil untuk membandingkan model berbeda
  • Multikolinearitas: prediktor yang berkorelasi tinggi satu sama lain menyebabkan estimasi tidak stabil
  • VIF (Variance Inflation Factor): mengukur tingkat multikolinearitas — VIF > 10 mengindikasikan masalah serius
  • F-test: uji apakah setidaknya satu prediktor signifikan secara keseluruhan

Keterangan:

  • p = jumlah prediktor
  • R^2_j = R^2 dari regresi Xj terhadap prediktor lainnya
  • SSR = Sum of Squares Regression
  • SSE = Sum of Squares Error
  • AIC/BIC digunakan untuk pemilihan model
  • nilai lebih kecil = model lebih baik.

Regresi Polinomial (Polynomial Regression)¶

Regresi Polinomial adalah perluasan regresi linear yang menambahkan suku pangkat (X^2, X^3, ...) untuk menangkap hubungan non-linear antara X dan Y. Meskipun model non-linear dalam X, ia tetap linear dalam parameter beta — sehingga tetap menggunakan estimasi OLS.

Kapan menggunakan regresi polinomial:

  • Scatter plot menunjukkan pola melengkung (bukan garis lurus)
  • Residual dari regresi linear membentuk pola sistematis
  • Ada teori yang mendukung hubungan kuadratik atau kubik

Overfitting sangat umum pada polynomial degree tinggi — selalu evaluasi pada test set dan pertimbangkan regularisasi.

Keterangan:

PolynomialFeatures(degree=d) menghasilkan 1 + C(p+d, d) fitur untuk p prediktor — untuk p=2, d=3 menghasilkan 10 fitur. Ini bisa menyebabkan curse of dimensionality jika p banyak.

Ridge Regression (Regularisasi L2)¶

Ridge Regression (Tikhonov Regularization) adalah modifikasi regresi linear yang menambahkan penalti L2 (jumlah kuadrat koefisien) pada fungsi loss. Penalti ini mencegah koefisien menjadi terlalu besar, yang merupakan penyebab utama overfitting dan instabilitas pada multikolinearitas. Ridge sangat efektif ketika:

  • Terdapat multikolinearitas (prediktor saling berkorelasi tinggi)
  • Jumlah prediktor lebih banyak atau hampir sama dengan jumlah observasi
  • Semua prediktor diyakini relevan dan perlu dipertahankan dalam model
  • Setelah polynomial expansion menghasilkan banyak fitur

Keterangan:

  • alpha = parameter regularisasi (lambda di beberapa referensi)
  • I = identity matrix, lambda_j = eigenvalue ke-j dari X^T*X.

Ridge selalu memiliki solusi unik bahkan ketika X^T*X singular (multikolinearitas sempurna). Koefisien Ridge lebih kecil dari OLS tapi tidak pernah menjadi nol.

Lasso Regression (Regularisasi L1)¶

Lasso (Least Absolute Shrinkage and Selection Operator) adalah regresi dengan penalti L1. Berbeda dari Ridge, penalti L1 dapat membuat koefisien menjadi tepat nol — secara otomatis melakukan feature selection. Ini sangat berguna ketika banyak prediktor tidak relevan. Mengapa Lasso bisa menghasilkan koefisien nol:

  • Geometri L1 norm berbentuk diamond — kemungkinan besar solusi optimal berada di sudut diamond (koordinat = 0)
  • Geometri L2 norm Ridge berbentuk lingkaran — solusi optimal hampir tidak pernah tepat di sumbu

Koordinate Descent adalah algoritma standar untuk Lasso karena tidak ada closed-form solution seperti Ridge.

Keterangan:

Soft thresholding adalah operasi kunci Lasso — koefisien yang lebih kecil dari alpha/2 dikunci ke nol; yang lebih besar dikurangi alpha/2. LARS (Least Angle Regression) memberikan Lasso path secara efisien dalam sekali komputasi.

Elastic Net Regression¶

Elastic Net menggabungkan penalti Ridge (L2) dan Lasso (L1) dalam satu model. Ini dirancang untuk mengatasi kelemahan masing-masing: Lasso tidak stabil dengan fitur berkorelasi tinggi, sementara Ridge tidak melakukan feature selection. Elastic Net sangat berguna pada kasus:

  • Fitur berkorelasi tinggi (multikolinearitas) + perlu feature selection
  • Jumlah fitur lebih besar dari observasi (p >> n) — seperti data genomik
  • Ingin kestabilan Ridge sekaligus sparsity Lasso
  • Tidak yakin apakah Lasso atau Ridge lebih tepat

Parameter l1_ratio mengontrol campuran: 0 = pure Ridge, 1 = pure Lasso, nilai antara = Elastic Net.

Keterangan:

alpha = kekuatan regularisasi total, r = l1_ratio (proporsi L1), Group Effect = properti Elastic Net di mana fitur berkorelasi tinggi cenderung memiliki koefisien yang serupa (tidak acak eliminasi seperti Lasso).

Regresi Logistik¶

Regresi Logistik adalah model regresi untuk variabel dependen biner (0/1) atau multinomial. Menggunakan fungsi logit (log-odds) untuk menghubungkan prediktor linear dengan probabilitas outcome. Meskipun sering digunakan untuk klasifikasi, secara formal ia adalah model regresi probabilistik. Tiga varian utama:

  • Binary Logistic: output 2 kelas (0 atau 1)
  • Multinomial Logistic: output > 2 kelas tanpa urutan
  • Ordinal Logistic: output > 2 kelas dengan urutan (misalnya: rendah/sedang/tinggi)

Keterangan:

p/(1-p) = odds, log(odds) = logit, exp(beta_j) = Odds Ratio — berapa kali lipat odds Y=1 jika Xj naik 1 unit (faktor lain konstan). Odds Ratio > 1: Xj meningkatkan probabilitas Y=1; < 1: menurunkan.

Regresi Kuantil (Quantile Regression)¶

Regresi Kuantil memodelkan hubungan antara prediktor dan kuantil tertentu dari distribusi Y (bukan rata-rata seperti OLS). Ini memberikan gambaran lengkap tentang distribusi Y kondisional, bukan hanya nilai tengahnya. Kapan menggunakan Quantile Regression:

  • Distribusi residual tidak simetris atau memiliki outlier ekstrem
  • Ingin memprediksi nilai ekstrem (kuantil bawah atau atas)
  • Efek prediktor berbeda di bagian bawah vs atas distribusi Y
  • Heteroskedastisitas (varians residual tidak konstan)

Contoh: memprediksi batas bawah (Q10) dan atas (Q90) harga sebagai range prediksi, atau memahami apakah faktor risiko berbeda untuk kejadian ringan vs berat.

Keterangan:

tau = kuantil target (0.1 = Q10, 0.5 = median, 0.9 = Q90), rho_tau = pinball loss / check function, beta(tau) = koefisien yang berbeda untuk setiap kuantil. Optimasi menggunakan Linear Programming karena tidak ada solusi closed-form.

Regresi Poisson (Poisson Regression)¶

Regresi Poisson adalah model regresi untuk data count (cacahan) — variabel Y yang berupa bilangan bulat non-negatif (0, 1, 2, 3, ...). Menggunakan fungsi log sebagai link function, memastikan prediksi selalu positif. Cocok untuk memodelkan:

  • Jumlah kecelakaan per tahun di suatu ruas jalan
  • Jumlah kunjungan ke dokter per bulan
  • Jumlah email spam yang diterima per hari
  • Jumlah pelanggan yang datang per jam

Asumsi utama: mean = variance (equidispersion). Jika variance > mean (overdispersion), gunakan Negative Binomial Regression sebagai alternatif.

Keterangan:

lambda = rata-rata count (expected), IRR = Incidence Rate Ratio (interpretasi multiplicative), exp(beta_j) > 1 berarti prediktor j meningkatkan rate, Offset digunakan saat observasi memiliki exposure time yang berbeda.

Cox Proportional Hazards Regression (Survival Analysis)¶

Cox Regression (Cox PH Model) adalah model semi-parametrik untuk analisis survival — memodelkan waktu hingga terjadinya suatu peristiwa (event) seperti kematian, kegagalan mesin, atau churn pelanggan. Model ini memperkirakan hazard ratio antar kelompok sambil mengakomodasi data yang tersensor (censored).

Konsep kunci survival analysis:

  • Survival function S(t): probabilitas 'bertahan' lebih dari waktu t
  • Hazard function h(t): laju kematian/kegagalan sesaat pada waktu t
  • Censoring: data di mana event belum terjadi saat studi berakhir (incomplete observation)
  • Hazard Ratio (HR): rasio hazard antara dua kelompok — interpretasi mirip Odds Ratio

Keterangan:

h_0(t) = baseline hazard (tidak diestimasi dalam Cox PH — 'semi-parametrik'), R(t_j) = risk set pada waktu t_j (orang yang masih at-risk), di = jumlah event pada ti, ni = jumlah at-risk pada ti. Asumsi proportional hazards: HR konstan terhadap waktu.

Robust Regression¶

Robust Regression adalah kumpulan metode regresi yang tidak sensitif terhadap outlier — berbeda dari OLS yang memberi bobot sama pada semua observasi dan sangat terpengaruh oleh nilai ekstrem. Metode robust memberikan bobot lebih kecil pada observasi yang jauh dari garis regresi.

Tiga pendekatan utama:

  • M-Estimators (Huber, Bisquare): meminimalkan fungsi loss yang lebih toleran terhadap outlier
  • MM-Estimators: kombinasi M-estimator dengan estimasi awal yang robust
  • Least Median of Squares (LMS) / Least Trimmed Squares (LTS): menghapus persentase tertentu observasi outlier

Keterangan:

k = tuning constant (Huber default k=1.345; Bisquare k=4.685), r_i = residual ke-i, psi = derivative dari loss function, IRLS = algoritma iteratif untuk M-estimators, h = jumlah observasi yang digunakan dalam LTS.

Regresi Non-Linear (Nonlinear Regression)¶

Regresi Non-Linear memodelkan hubungan di mana Y adalah fungsi non-linear dari parameter (bukan hanya dari X). Berbeda dari Polynomial Regression yang non-linear dalam X tapi linear dalam parameter, Nonlinear Regression memiliki parameter yang muncul secara non-linear dalam model.

Contoh model non-linear:

  • Exponential growth: Y = a * exp(b*X) — pertumbuhan populasi, komponen diskon
  • Logistic growth: Y = L / (1 + exp(-k*(X-x0))) — difusi teknologi, epidemi
  • Power law: Y = a * X^b — hubungan allometric, hukum scaling
  • Michaelis-Menten: Y = Vmax*X / (Km + X) — kinetika enzim, farmakokinetik
  • Gompertz: Y = a * exp(-bexp(-cX)) — pertumbuhan tumor, mortalitas

Keterangan:

J = Jacobian matrix (matrix partial derivatives f terhadap beta), r = residual vector, Gauss-Newton dan Levenberg-Marquardt (LM) adalah algoritma iteratif untuk NLS. LM lebih stabil karena kombinasi Gradient Descent (lambda besar) dan Gauss-Newton (lambda kecil).
